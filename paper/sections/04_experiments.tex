\section{Experimental Setup}

\subsection{Benchmark Dataset and Annotation Protocol}
To evaluate the proposed section-aware matching architecture on reproducible, open-science foundations without insular corporate bias, all experiments are conducted on the standardized international benchmark \textsc{resume-job-description-fit}~\cite{huggingface_resume_fit}.

The benchmark comprises:
\begin{itemize}
    \item \textbf{Corpus Scale}: $1,759$ authentic candidate resume and job description pairs spanning $71$ unique job queries and $477$ distinct candidate resumes across diverse technology and business domains.
    \item \textbf{Graded Relevance Rubric}: Each pair is annotated under a 3-tier graded relevance scale:
    \begin{itemize}
        \item \textbf{Grade 0 (\textit{No Fit})}: $857$ pairs ($48.7\%$) representing negative distractors where candidate competencies fail core prerequisites.
        \item \textbf{Grade 1 (\textit{Potential Fit})}: $444$ pairs ($25.2\%$) indicating partial competency overlap where candidate exhibits transferable skills but lacks secondary requirements.
        \item \textbf{Grade 2 (\textit{Good Fit})}: $458$ pairs ($26.1\%$) denoting high alignment with mandatory experience and technical prerequisites.
    \end{itemize}
\end{itemize}

\subsection{Baseline Configurations and Model Deployments}
We benchmark a comprehensive suite of algorithmic configurations across lexical, flat dense, chunk-based, multi-vector, hybrid, long-context, and cross-attention paradigms:
\begin{enumerate}\setlength{\itemsep}{1pt}\setlength{\parskip}{0pt}
    \item \textbf{Lexical Baseline (BM25 / TF-IDF)}: Standard Okapi BM25 with English stop-word removal and sublinear term frequency scaling over raw document text.
    \item \textbf{Flat Dense Bi-Encoder (MiniLM)}: Dense bi-encoder Cosine similarity over whole-document text mapped via \texttt{sentence-transformers/\allowbreak{}all-MiniLM-L6-v2} ($384$-dimensional embedding, $256$ maximum sequence length, leading to truncation of longer resumes).
    \item \textbf{Chunk-Mean (MiniLM)}: Fixed-size sliding-window tokenization ($128$-word window, $64$-word stride) where chunk embeddings are mean-pooled into a single representation prior to cosine scoring.
    \item \textbf{Chunk-MaxSim (ColBERT Late Interaction)}: Fine-grained token/chunk interaction computing $\frac{1}{|Q|}\sum_{q \in Q} \max_{d \in D} \cos(q, d)$ across sliding-window chunks.
    \item \textbf{Section-Aware Multi-Vector (Ours)}: Functional section parsing via the frozen parser (commit \texttt{41e1d27}) with section-specific vector representations and cross-section alignment. We evaluate three variants: Pure ($0\%$ single-vector), Fallback (single-vector only if $0$ sections recognized), and Mixed ($0.65$ section + $0.35$ single-vector).
    \item \textbf{Long-Context Encoder (\textsc{BAAI/bge-m3})}: State-of-the-art multilingual model with an $8,192$-token context window ($1,024$-dim embedding), evaluated in both Flat and Section-Aware configurations.
    \item \textbf{Calibrated Hybrid Fusion (Ours)}: Two-tier fusion integrating min-max normalized section-aware semantic retrieval ($\alpha = 0.60$), BM25 lexical precision ($1 - \alpha = 0.40$), and structured 3-tier skill taxonomy coverage.
    \item \textbf{Parameter-Free RRF + Taxonomy (Ours)}: Reciprocal Rank Fusion ($k=60$) between dense section-aware and lexical BM25 ranks, combined with structured taxonomy coverage without hyperparameter tuning.
    \item \textbf{Zero-Shot Cross-Encoder}: Deep cross-attention ranking over concatenation $(D_q, D_c)$ via \texttt{cross-encoder/\allowbreak{}ms-marco-MiniLM-L-6-v2}.
    \item \textbf{Cascaded 2-Stage Retrieval}: Practical two-stage pipeline where Calibrated Hybrid retrieves Top-$K$ candidates ($K \in \{10, 20\}$) which are then reranked by the Cross-Encoder.
\end{enumerate}

\subsection{Evaluation Metrics and Significance Testing}
Following standard Information Retrieval (TREC) and Recommender Systems conventions, ranking quality is evaluated across multiple complementary dimensions:
\begin{itemize}\setlength{\itemsep}{1pt}\setlength{\parskip}{0pt}
    \item \textbf{Discounted Cumulative Gain}: nDCG@5 and nDCG@10 assessing graded ranking quality at top recommendation thresholds.
    \item \textbf{Reciprocal Rank \& Precision}: Mean Reciprocal Rank (MRR), Mean Average Precision (MAP), and Precision@5 (P@5) evaluated at relevance threshold $\ge 1$.
    \item \textbf{Rank Correlation}: Spearman rank correlation coefficient evaluated both as Macro-Spearman ($\rho_{\text{mac}}$, average per-query correlation across queries) and Pooled Micro-Spearman ($\rho_{\text{mic}}$, global correlation over all pairs).
    \item \textbf{Paired Bootstrap Confidence Intervals}: Empirical $95\%$ confidence intervals for paired differences ($\bar{\Delta}$) computed over $10{,}000$ bootstrap resamples across query groups.
    \item \textbf{Operational Latency Profile}: Decomposed into offline indexing time ($T_{\text{index}}$), online query encoding ($T_{\text{query}}$), and candidate scoring/ranking latency ($T_{\text{rank}}$) for pool size $N=25$ candidates on commodity multi-core CPUs.
\end{itemize}

\subsection{Section Parser Fidelity Evaluation Protocol}
To evaluate section parser fidelity without data contamination, heading boundaries on $50$ held-out development documents ($25$ CVs, $25$ JDs, sampled from \texttt{train\_eval} with fixed seed $42$) were independently reviewed against raw document text. We evaluate rule-consistency precision, recall, and false positive rates before freezing the parser (commit \texttt{41e1d27}) for all downstream test benchmark experiments.

\subsection{Reproducibility Environment}
All benchmarks execute on an Intel Core i7 multi-core CPU (16\,GB RAM) under Python 3.13 without specialized GPU hardware. All code, frozen taxonomy configurations ($70+$ canonical technologies with verified relational weights), and evaluation scripts are open-sourced for complete scientific auditability.
